### 3. [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5) ✰ 10,460

**解决什么问题**
该项目旨在解决 PlayStation 5 游戏在非 PS5 硬件上运行的问题，通过将 PS5 原生可执行文件转换为 Linux 或 Windows 的原生格式，并提供索尼系统模块（PRX 库）的本地动态链接库等效项，从而实现兼容性、研究和保存的目的。它避免了 CPU/GPU 仿真或单独的运行时访客进程。

**核心功能**
AnyPS5 的核心功能包括一个重链接器（relinker），用于将访客可执行文件转换为目标系统的原生格式。它还实现了索尼系统 PRX 库，例如 `libc` 和 `libkernel`，这些库将访客 API 调用直接桥接到本地操作系统和图形原语。此外，它还包含一个着色器重编译器模块，用于将访客 AMD RDNA 着色器二进制文件翻译成中间表示（IR），最终生成用于 Vulkan 的 SPIR-V 着色器。

**技术亮点**
该项目的技术亮点在于其独特的移植方法，即通过重链接器将 PS5 可执行文件转换为原生格式，而不是使用传统的模拟方式。它通过实现 `PRX` 库来处理系统调用，并使用 NID（Name ID）机制来解析函数和数据引用。着色器重编译器能够将 RDNA 着色器转换为 SPIR-V，以在现代 GPU 上运行。项目状态显示，音频和视频输出初始化已通过，并能达到访客 `main` 函数的渲染循环。

**适合谁用**
AnyPS5 适合对 PlayStation 5 软件的互操作性、研究、保存和兼容性感兴趣的开发者和研究人员。它为那些希望在 Linux 或 Windows 环境下分析、修改或运行 PS5 原生应用程序的用户提供了一个工具链，而无需依赖昂贵的开发套件或复杂的仿真设置。

*   **RAD 链接器 (radlink)**：一个高性能、多线程的 PE/COFF 链接器，旨在替代 MSVC 链接器。它针对速度进行了优化，并可以在链接过程中直接生成 RDI 调试信息，从而消除按需转换时间。

*   **高性能链接器**：RAD Linker 针对大型项目进行了优化，通过多线程和支持大内存页来显著提高链接速度。
*   **分层架构**：项目采用分层架构，确保低层级对高层级无感知，提高了模块化和可维护性。
*   **即时模式 UI**：调试器使用自定义的即时模式 UI 系统，提供响应迅速的用户体验。
