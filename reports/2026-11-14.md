### 1. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) ✰ 50,351

**解决什么问题**  
针对通用 Agent 审查变更时可能覆盖不全、评论位置偏移、结果不稳定等问题，提供更有约束、低噪声的代码审查流程。

**核心功能**  
读取 Git diff 并生成行级结构化意见；支持工作区、分支范围和单次提交审查，也可用 `ocr scan` 扫描完整文件或目录。Agent 能读取文件、搜索代码库并结合其他变更获取上下文；还支持委托模式及 JSON 输出。

**技术亮点**  
采用确定性工程与 Agent 混合架构：工程逻辑负责文件筛选、关联文件分组和规则匹配，Agent 负责动态决策与上下文探索；独立定位和反思组件提升评论的位置与内容准确性。

**适合谁用**  
适合希望在本地开发或 CI 流程中提升审查质量的开发者与团队，也适用于需要审计陌生代码库、扫描完整文件，或将审查集成到编程 Agent 和内部系统的场景。
