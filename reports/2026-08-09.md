### 1. [PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent) ✰ 8,868

**解决什么问题**
Prime Agent 旨在解决传统 LLM 在处理长期、复杂任务时遇到的上下文丢失和状态管理问题。它通过持久化的 IPython 内核和可精炼的持续性 Harness 机制，使得代理能够跨会话保留工作上下文和可重用操作模式，从而实现自我改进和持续工作。

**核心功能**
Prime Agent 的核心功能包括：
*   **递归语言模型 (RLM)**：将 LLM 上下文视为变量空间，并支持将递归子代理作为程序化函数调用。
*   **持续性 Harness**：存储补充提示、记忆、技能描述和可重用子代理规范，并通过 `/refine` 命令进行证据驱动的更新。
*   **程序化一切**：文件操作、shell 命令、工具使用和上下文管理都通过代码在持久化的 IPython 环境中进行。
*   **会话管理**：会话以 JSONL 文件格式存储，支持分支和树状导航，并自动保存。

**技术亮点**
*   **多模式 CLI**：支持交互式 TUI、单次执行的 Print 模式、结构化事件流的 JSON 模式、双向 JSONL 通信的 RPC 模式以及 ACP 协议。
*   **模块化架构**：项目采用 Monorepo 结构，包含 `pi-coding-agent` (CLI 和 TUI)、`pi-agent-core` (核心代理逻辑)、`pi-ai` (LLM 抽象层) 和 `pi-tui` (终端 UI 库) 等 TypeScript 包，以及 `prime-agent-runtime` Python 包。
*   **可扩展性**：支持通过 TypeScript 模块实现扩展、Python 技能、提示模板和自定义主题，允许用户高度定制代理行为和界面。

**适合谁用**
Prime Agent 适合需要处理通用、长期和复杂编码及研究任务的开发者和研究人员。特别是那些希望代理能够：
*   在终端会话之间保持上下文和进度。
*   通过编程方式控制文件操作、shell 命令和工具使用。
*   利用子代理进行并行或后台工作。
*   通过迭代和证据驱动的更新来改进其操作模式。
*   自定义代理功能和界面。

### 12. [bannedbook/fanqiang](https://github.com/bannedbook/fanqiang) ✰ 49,871

**解决什么问题**
本项目旨在解决互联网审查导致的用户无法自由访问特定内容的问题。它通过提供预配置的翻墙工具包，简化了技术设置，让用户能够绕过网络限制，访问被屏蔽的网站和服务。 

**核心功能**
核心功能是提供针对不同操作系统和浏览器的“一键翻墙包”，例如 `ChromeGo` (Windows), `EdgeGo` (Windows), `ChromeGoMac` (macOS) 和 `FirefoxFqLinux` (Linux)。  每个包都集成了 `clash`、`Xray`、`v2go`、`hysteria`、`singbox`、`naiveproxy`、`psiphon` 等多种翻墙技术，并内置免费服务器，持续更新。    

**技术亮点**
项目集成了多种主流翻墙协议和工具，如 `Clash`、`Xray`、`V2Ray`、`Hysteria`、`SingBox`、`NaiveProxy` 和 `Psiphon`，以适应复杂的网络环境。  它还提供了IP/服务器更新脚本，以应对封锁变化，并强调了避免国产杀毒软件干扰的重要性。 

**适合谁用**
本项目适合需要快速、简便翻墙解决方案的用户，特别是那些不具备复杂技术配置知识的用户。  由于不同地区网络环境差异，用户需要自行尝试不同工具以找到最适合自己的方案。
