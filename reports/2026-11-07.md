**适合谁用**

**适合谁用**
React 适合需要构建交互式、高性能用户界面的开发者。无论是开发单页应用、复杂的企业级应用，还是移动应用（通过 React Native），React 都能提供强大的支持。对于希望减少手动性能优化工作、提高开发效率并确保应用性能的开发者，React Compiler 提供了自动化的解决方案。

### 26. [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context) ✰ 4,452

**解决什么问题**
AI 编码会话中，工具输出、日志等信息会迅速填满上下文窗口，导致模型性能下降或会话中断，同时增加 token 费用。  `billion-context` 旨在解决这一问题，让 AI 编码代理能够在有限的上下文窗口内进行长时间、高质量的工作。 

**核心功能**
`billion-context` 作为代理运行在 AI 编码代理和模型 API 之间，通过 `acp-kernel` 压缩引擎对对话进行增量、可逆且对前缀缓存友好的压缩。   它会注入 `compress`、`decompress`、`search_context` 和 `acp_status` 四个上下文管理工具，由模型自主决定何时以及如何压缩内容。 

**技术亮点**
该项目采用模型驱动的增量分层压缩技术，将历史对话折叠成多层摘要，确保最近的上下文保持完整。   压缩是增量的，每次只压缩新增内容，且可按需解压，保持了前缀缓存的有效性。  实验数据显示，可将 token 消耗降低多达 5 倍，并支持数月长的会话，累计处理数十亿 token。  

**适合谁用**
`billion-context` 适用于使用各种 AI 编码代理的开发者，包括但不限于 pi、opencode、omp、dsh、kimi、hermes、zcode、claude、codex 等。  它支持原生插件、启动器和通用代理三种接入方式，无需修改客户端源码即可透明接入。
