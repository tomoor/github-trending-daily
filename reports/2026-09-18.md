### 1. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) ✰ 34,655

**解决什么问题**
本项目旨在解决通用 AI Agent 在代码审查中存在的覆盖不全、位置漂移和质量不稳定等问题。通过结合确定性工程和 LLM Agent，确保审查的准确性和稳定性，同时降低误报率。

**核心功能**
*   **深度上下文审查**：Agent 能够读取完整文件内容、搜索代码库并检查相关文件，提供深入的架构反馈，而非仅限于表面 diff 分析。
*   **多模式操作**：支持审查本地工作区变更、特定 Git 分支差异、单个提交，或通过 `ocr scan` 对整个文件进行全面审计。
*   **多模型协议支持**：支持 Anthropic Messages API、OpenAI Chat Completions API 和 OpenAI Responses API，并内置多种预设提供商，同时支持自定义模型端点。
*   **内置审查规则**：提供经过大规模真实场景验证的审查规则，覆盖 40 多种语言和文件类型，包含 NPE、线程安全、XSS、SQL 注入等专项检查。

**技术亮点**
*   **混合架构：确定性工程 × Agent**：将确定性工程（如文件筛选、行号定位、规则匹配）与 LLM Agent 推理（风险检测、上下文探索）解耦，优化质量、Token 成本和速度。
*   **精准评论定位与反思**：独立的行级评论定位模块采用三级渐进式 LLM 策略，确保评论精确定位到具体行号；独立的反思模块能提前拦截幻觉和知识偏移。
*   **智能记忆压缩**：专为代码审查构建的三级分区（冻结/压缩/活跃）上下文管理方案，突破 Token 限制，实现深度审查。
*   **Effort 驱动的多轮递进审查**：Agent 审查深度可控，从快速反馈到关键变更，当一轮探索不再产出新风险时自动收敛，避免不必要的成本。

**适合谁用**
*   **独立开发者**：将 Open Code Review 嵌入本地 AI 辅助开发工作流，获得即时、高质量的代码审查反馈。
*   **平台团队**：无缝集成到内部系统，完全掌控数据流和审查策略。
*   **ML 研究者**：作为强化学习 (RL) 训练流水线中的代码质量验证器，为代码生成模型提供可靠的奖励信号。

### 2. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) ✰ 10,542

**解决什么问题**
该项目旨在解决传统安全审计中发现可利用漏洞效率低下的问题，通过自动化流程和多智能体协作，提高漏洞发现的覆盖率和准确性，并减少误报。

**核心功能**
该项目通过一个六阶段的流水线进行安全审计：
*   **侦察 (Recon)**：并行研究代理映射应用程序的架构、信任边界和输入接口，生成 `architecture.md`。
*   **漏洞搜寻 (Hunt)**：并行通用代理从不同角度（如注入、访问控制、业务逻辑等）攻击代码库，每个代理都可以生成子代理进行深入调查。
*   **验证 (Validate)**：独立的代理尝试反驳每个发现的漏洞，以消除误报。
*   **报告 (Report)**：生成人类可读的 `REPORT.md` 和包含详细数据流的 `FINDINGS-DETAIL.md`。
*   **结构化输出 (Structured output)**：生成符合 `report-schema.json` 规范的 `findings.json` 文件。
*   **独立验证 (Independent verification)**：新的代理独立验证结构化输出中所有事实声明的准确性。

**技术亮点**
该项目利用多代理并行协作，通过“侦察-搜寻-验证-报告-结构化输出-独立验证”的六阶段流水线，确保漏洞发现的全面性和准确性。 特别强调对抗性验证，即由独立的代理尝试反驳发现的漏洞，以减少误报。 此外，它还支持多次运行以提高覆盖率，并能利用之前的审计结果来跳过已知问题和填补空白。

**适合谁用**
该项目适合需要对代码库进行安全审计、漏洞审查或渗透测试的开发者和安全工程师。 它可以用于审计各种类型的代码库，包括 Web 应用程序、API、服务、CLI 工具、库和守护程序等。

### 4. [Tencent/BrowserSkill](https://github.com/Tencent/BrowserSkill) ✰ 4,088

**解决什么问题**
BrowserSkill 解决了 AI Agent 无法直接与用户浏览器交互的问题，同时确保 Agent 操作不干扰用户正常工作。 它允许 Agent 复用用户已登录的会话状态，避免了为 Agent 维护单独测试账号的麻烦。 此外，它还提供了“human-in-loop”机制，在遇到验证码、登录等需要人工干预的步骤时，Agent 可以暂停并请求用户协助。

**核心功能**
BrowserSkill 的核心功能包括：
*   **Agent 浏览器自动化**：通过 `bsk` CLI 接收 AI Agent 的指令，并在浏览器中执行导航、点击、填写等操作。
*   **独立 Agent 窗口**：所有 Agent 任务都在一个独立的“Agent Window”中运行，确保用户可以继续使用自己的浏览器而不受影响。
*   **会话状态复用**：Agent 可以利用用户已登录的真实会话状态进行操作，无需重新登录。
*   **人机协作**：提供 `bsk request-help` 命令，允许 Agent 在需要时请求用户介入处理复杂或需要人工确认的步骤。

**技术亮点**
*   **Rust CLI/Daemon 与 TypeScript 浏览器扩展**：项目采用 Rust 构建 CLI 和后台守护进程，提供高性能和系统级集成；浏览器扩展则使用 TypeScript 开发，负责与浏览器进行交互。
*   **Chrome DevTools Protocol (CDP)**：扩展通过 CDP 实现对浏览器的精细控制和自动化操作。
*   **模块化架构**：采用 monorepo 结构，包含 `bsk-cli`、`bsk-protocol` 和 `apps/extension` 等模块，职责分离清晰。
*   **跨平台支持**：支持 macOS、Linux 和 Windows 操作系统，以及 Chrome 和 Microsoft Edge 等主流 Chromium 内核浏览器。

**适合谁用**
BrowserSkill 适合需要 AI Agent 执行浏览器自动化任务的开发者和用户。 特别是那些使用 Cursor、Claude Code、Codex 等支持 Shell 的 AI Agent，并希望 Agent 能在真实浏览器环境中，利用现有登录状态完成复杂网页操作的用户。 它也适用于希望在 Agent 执行任务时，不中断自己浏览器使用体验的用户。

### 20. [n8n-io/n8n](https://github.com/n8n-io/n8n) ✰ 204,961

**解决什么问题**
n8n 旨在解决不同应用程序和服务之间的数据流和任务自动化问题。它通过提供一个低代码/无代码平台，让用户能够轻松创建、执行和监控由相互连接的节点组成的工作流，从而减少手动操作和提高效率。
