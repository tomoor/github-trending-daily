**核心功能**
`agent-browser` 提供了一系列核心功能，包括：
*   **快照-引用工作流**：通过 `snapshot` 命令生成可访问性树，并为交互元素分配唯一的引用（如 `@e1`），AI 代理可以使用这些引用进行精确操作。 
*   **持久化守护进程与会话**：守护进程在后台运行，维护浏览器状态（如 cookies、tabs），并支持命名会话以实现隔离和状态持久化。 
*   **WebMCP (实验性)**：一种发现和调用网页直接提供的工具的机制，支持框架感知的工具选择。 
*   **安全与边界**：包括内容边界（`BOUNDARY_NONCE`）和输出截断（`truncate_if_needed`）等功能，以防止提示注入和上下文溢出，并支持域名白名单。 
*   **可观测性与仪表盘**：提供 Next.js Web UI 用于实时会话查看、屏幕录制和活动反馈。 

**技术亮点**
该项目采用 Rust 编写的本地 CLI 和守护进程，实现了高性能和低延迟。  它使用 Chrome DevTools Protocol (CDP) 直接控制 Chrome 浏览器，无需依赖 Playwright 或 Puppeteer。  其客户端-守护进程-浏览器架构优化了性能，将热命令延迟降低至约 1ms。 

**适合谁用**
`agent-browser` 适用于需要进行网页导航、数据提取和自动化测试的 AI 代理，特别是那些对性能、确定性和 token 使用效率有高要求的场景。  它支持多种 AI 编码助手，如 Claude Code、GitHub Copilot 等。

**核心功能**
MuJoCo 提供了一个 C/C++ 库，具有 C API，用于高性能物理模拟。 它支持通过 MJCF XML 格式或 URDF 文件定义模型，并将其编译为高效的运行时数据结构。 核心功能包括软性、凸面和可解析反演的接触动力学、肌腱几何建模、通用驱动模型以及可重构的计算管道。 它还将模型 (`mjModel`) 和动态数据 (`mjData`) 分离，便于多线程和并行计算。

**技术亮点**
MuJoCo 的技术亮点在于其独特的物理建模方法，它将广义坐标系下的高效递归算法与基于优化的接触动力学相结合。 它采用凸优化问题来解决摩擦接触力，支持软接触，并具有独特的逆动力学定义。 引擎在运行时不进行内存分配，所有工作内存都在 `mjData` 中预分配，以实现高性能。 此外，它还提供了交互式可视化工具和 Python 绑定。 对于加速计算，MuJoCo 提供了 MJX (JAX) 和 MJWarp (CUDA) 后端，支持 GPU/TPU 上的批处理模拟和可微分物理。

**适合谁用**
MuJoCo 适合需要进行快速、准确物理模拟的研究人员和开发人员。 具体应用领域包括机器人学、生物力学、图形和动画、以及机器学习（特别是强化学习）等。 对于需要高性能、高精度模拟以及希望利用 GPU/TPU 进行大规模并行计算的用户，MuJoCo 及其加速后端是理想选择。

### 9. [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context) ✰ 5,117

**解决什么问题**
AI 编码会话中，上下文窗口会因工具输出、日志和文件读取等快速堆积而耗尽，导致模型性能下降或会话中断。`billion-context` 旨在解决这一问题，通过上下文压缩，使得 100K 窗口的模型也能支持月级长会话，并显著降低 token 消耗。

**核心功能**
`billion-context` 作为本地代理运行在 AI 编码代理和模型服务之间。它维护一个 token 级账本，将对话中较旧的部分压缩成摘要，同时保持最新内容逐字节不变。它支持两种集成方式：插件模式（Agent 自行执行压缩）和代理模式（代理在服务端执行压缩）。项目提供内置 Web UI，用于查看会话统计、配置和实时日志。

**技术亮点**
该项目采用“折叠而非重写”的策略，将历史对话折叠成紧凑的摘要块，确保服务商的缓存保持温热，从而实现高达 5 倍的 token 节省。压缩时机由模型决定，并在增长门槛触发时进行。每个 token 的使用都有详细记录，可在内置 Web UI 或终端中审计。

**适合谁用**
`billion-context` 适用于使用 AI 编码代理的开发者，特别是那些需要长时间、高效率编码会话的用户。它兼容多种主流 AI 编码代理，如 pi、omp、claude、codex 等，并提供灵活的安装和接入方式，包括原生插件、启动器和通用代理模式。
