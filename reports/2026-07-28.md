### 4. [andrewyng/aisuite](https://github.com/andrewyng/aisuite) ✰ 15,553

aisuite 是一个轻量级 Python 库，用于构建 LLM 应用，提供统一的 API 接口和强大的代理功能，同时包含桌面 AI 助手 OpenCoworker。

## 解决什么问题
该项目旨在解决大型语言模型（LLM）应用开发中的碎片化问题，通过提供一个统一的 API 接口，让开发者无需处理不同 LLM 提供商 SDK 的差异。它还通过代理 API 简化了工具调用和多轮对话的复杂性，并提供了一个桌面 AI 助手 OpenCoworker 来执行日常任务和自动化。

## 核心功能
aisuite 包含三个主要层级：
1.  **Chat Completions API**：提供一个统一的、类似 OpenAI 的接口，支持包括 OpenAI、Anthropic、Google、Mistral 等在内的 20 多个 LLM 提供商。开发者可以通过改变一个字符串来切换模型。
2.  **Agents API**：允许模型调用真实的 Python 函数作为工具，支持多轮对话、预构建的工具包（文件、Git、Shell）以及模型上下文协议（MCP）集成。
3.  **OpenCoworker**：一个基于 aisuite 构建的桌面 AI 助手应用，能够在用户的电脑上执行深度研究和任务，例如阅读文件、发送消息、创建报告和支持计划自动化。

## 技术亮点
*   **统一接口**：通过 `<provider>:<model-name>` 格式的模型名称，aisuite 能够将调用路由到正确的提供商，并转换参数和响应，实现提供商无关的 LLM 交互。
*   **工具调用抽象**：将 Python 函数直接作为工具传递给模型，aisuite 自动生成 schema 并执行调用，简化了工具集成。
*   **代理框架**：提供 `Agent` 和 `Runner` 类，支持工具策略、状态存储和追踪，用于构建持久化和可观测的代理应用。
*   **本地模型支持**：通过 Ollama 等工具支持本地运行模型，无需 API 密钥，确保数据隐私。
*   **模块化设计**：新提供商可以通过实现轻量级适配器轻松添加，遵循命名约定实现自动加载。

## 适合谁用
*   **LLM 开发者**：希望简化多提供商 LLM 集成，并快速构建代理应用的开发者。
*   **需要自动化日常任务的用户**：通过 OpenCoworker 桌面应用，用户可以利用 AI 助手进行文件管理、信息检索、报告生成和计划自动化。
*   **注重数据隐私的用户**：OpenCoworker 确保 API 密钥、对话和文件都保留在用户本地机器上，不上传到任何后端服务器。
