### 1. [tt-a1i/archify](https://github.com/tt-a1i/archify) ✰ 26,898

**解决什么问题**
Archify 旨在解决传统技术图表绘制效率低、难以保持一致性、以及在大型语言模型（LLM）环境中生成图表时缺乏精确控制和验证的问题。它通过将自然语言描述转化为结构化的 JSON 中间表示（IR），并进行确定性编译和严格校验，确保生成的图表专业、可信且易于分享和迭代。  

**核心功能**
Archify 的核心功能包括：
*   **多类型图表生成**：支持架构图、工作流图、时序图、数据流图和生命周期图五种主要技术图表类型。  
*   **Agent 技能集成**：作为 LLM 的 Agent 技能，能够将用户在聊天中描述的系统或代码仓库信息转化为图表。 
*   **确定性渲染与校验**：通过 Typed JSON IR 和内置校验器，确保图表的几何布局、线路和标签等都经过严格检查，并能生成结构化修复回执。  
*   **交互式与可分享输出**：生成独立的 HTML 文件，支持深浅主题切换、多种视觉预设、节点搜索、路径追踪、语义角色对比和故事播放等交互功能，并可导出为 PNG、SVG、WebM 等格式。  

**技术亮点**
*   **Agent-first 设计**：专注于为 LLM 提供稳定、机器可读的诊断和合同，优化 Agent 生成和迭代图表的体验。 
*   **语义化色彩系统**：为基础设施组件定义了七种语义色彩，并提供协调的深浅主题变体。  
*   **零依赖输出**：生成的 HTML 文件是自包含的，无需服务器或构建工具即可在任何浏览器中打开。 
*   **高保真导出**：支持 4 倍分辨率的 PNG、JPEG、WebP 导出，以及支持双主题的 SVG 矢量导出。 

**适合谁用**
Archify 适合需要快速、准确生成和分享技术图表的开发者、架构师以及使用 LLM 进行辅助开发的工程师。特别是那些希望通过自然语言描述来创建专业、可验证图表，并能在聊天环境中直接迭代和协作的用户。
