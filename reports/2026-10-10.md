### 1. [morluto/rea](https://github.com/morluto/rea) ✰ 45,277

**解决什么问题**
REA 旨在解决软件开发中“黑盒”问题，即在没有源代码的情况下理解软件功能和行为的挑战。它提供了一种系统化的方法，让智能体能够分析应用程序、解释功能工作原理并提供证据，最终帮助开发者在自己的项目中实现类似功能。

**核心功能**
REA 的核心功能包括：
*   **反编译与分析**：能够打开原生应用或可执行文件，恢复过程、伪代码、汇编、字符串、符号、段和元数据。
*   **理解与追踪**：通过追踪调用者、被调用者、交叉引用和调用图，帮助智能体理解功能或算法的实际工作方式。
*   **重建与实现**：将智能体学到的内容转化为适合特定技术栈、界面和需求的产品功能。
*   **多类型应用支持**：提供原生二进制、JavaScript 与 Electron 应用、.NET 程序集和网站的分析工具。

**技术亮点**
REA 的技术亮点在于其为智能体设计，通过 CLI 和 MCP（Model Context Protocol）服务器，将逆向工程能力暴露给 AI 编程助手。它支持多种分析工具，如 Hopper 和 Ghidra，并在本地运行分析，确保数据安全。REA 还通过引导式设置简化了配置过程，并能保留上下文，支持连续调查多个应用。

**适合谁用**
REA 适合需要理解现有软件功能、行为或实现细节的开发者和团队。特别是当缺乏源代码时，它能帮助用户通过逆向工程获取洞察。它也适用于希望利用 AI 编程助手加速逆向工程和功能重建过程的工程师，以及需要分析不同类型二进制文件（如原生应用、JavaScript/Electron 应用、.NET 程序集和网站）的专业人士。

### 2. [boykopovar/AnyPS5](https://github.com/boykopovar/AnyPS5) ✰ 22,203

**解决什么问题**
该项目解决了 PlayStation 5 游戏和应用程序在非原生 Linux 和 Windows 系统上运行的问题，无需 CPU/GPU 模拟或单独的运行时客户进程。它通过将客户可执行文件转换为原生格式并提供索尼系统模块（`PRX` 库）的原生动态链接库等效项来实现这一点。

**核心功能**
核心功能包括一个重链接器，用于将 PS5 可执行文件转换为目标系统的原生格式，以及实现索尼系统 `PRX` 库（如 `libc`、`libkernel` 和 `libSce*` 服务模块）。它还包含一个着色器重编译器，可将 AMD RDNA 着色器二进制文件转换为 SPIR-V 着色器以供 Vulkan 使用。

**技术亮点**
技术亮点在于其无模拟的移植方法，通过重链接器将客户 ELF 可执行文件重写为原生 Linux ELF 或 Windows PE 二进制文件。它还实现了对 PS5 系统库的直接桥接，将客户 API 调用映射到原生操作系统和图形原语。项目支持 SDL 映射的游戏控制器，包括模拟摇杆和扳机。

**适合谁用**
该项目适用于希望在 Linux 和 Windows 系统上运行 PS5 原生可执行文件的开发者、研究人员和用户。它也适用于对互操作性、研究、保存和兼容性感兴趣的人。

**适合谁用**

该项目旨在解决 SwiftUI 代码质量、现代化和可维护性方面的问题。它通过自动化代码审查，帮助开发者确保代码使用现代 SwiftUI API (iOS 26+, Swift 6.2+)，遵循可访问性最佳实践，避免性能陷阱，并符合 Apple 的人机界面指南。它特别针对 AI 模型常犯的错误，如 VoiceOver 不可见按钮、使用废弃 API 和导致性能问题。

**核心功能**
该技能提供一个 9 步的代码审查流程，涵盖 API 使用、视图结构、数据流、导航、设计、可访问性、性能、Swift 实践和代码卫生等多个方面。它能生成结构化的审查报告，包含按文件组织的发现、问题行号、违反的规则名称以及修改前后的代码示例。用户可以通过明确命令、自然语言或隐式上下文触发审查。

**技术亮点**
该项目采用 Agent Skills 格式构建，可无缝集成到 Claude Code、Codex、Gemini、Cursor 等多种 AI 编码平台。它设计为 token 高效，专注于边缘情况、软弃用和 AI 模型常犯的错误，而非重复已知信息。技能的核心是一个协调器 (`SKILL.md`) 和九个领域特定的参考文件 (`references/*.md`)，共同构成专家知识库。

**适合谁用**
该技能适合 SwiftUI 开发者，特别是那些希望确保其代码符合最新 SwiftUI 最佳实践、提高代码质量、避免常见错误并优化性能的开发者。它也适用于使用 AI 编码工具的开发者，帮助他们弥补 AI 在 SwiftUI 代码生成方面可能存在的不足。
