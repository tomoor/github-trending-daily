### 1. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) ✰ 31,735

**解决什么问题**
传统的通用AI代码审查工具存在覆盖不全、评论位置漂移和质量不稳定等问题。OCR通过其混合架构解决了这些问题，确保了审查的准确性和稳定性。它能帮助开发者发现代码缺陷，提升代码质量，并降低人工审查成本。

**核心功能**
OCR能够读取Git diff，通过Agent将变更文件发送给可配置的LLM，生成行级精度的结构化审查意见。它支持多种审查模式，包括工作区变更、Git分支比较、特定提交审查以及全文件扫描（`ocr scan`）。此外，它还具备智能文件打包、精细化规则匹配和外部定位与反思组件等功能，以提高审查的准确性和效率。

**技术亮点**
该项目采用“确定性工程 × Agent 混合驱动”的核心设计理念。确定性工程负责文件筛选、文件打包、规则匹配和评论定位等“不能出错”的环节。Agent则专注于动态决策和上下文召回，通过场景化提示词调优和工具集沉淀，优化LLM的推理能力。它支持Anthropic Messages API、OpenAI Chat Completions API等多种模型协议。

**适合谁用**
OCR适合个人开发者，可将其嵌入本地AI辅助开发工作流，获得即时、高质量的代码审查反馈。平台团队可以无缝集成到内部系统，完全掌控数据流和审查策略。ML研究者可将其作为RL训练流水线中的代码质量验证器，为代码生成模型提供可靠的奖励信号。

### 2. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) ✰ 7,122

**解决什么问题**

该项目旨在解决传统安全审计中效率低下、容易遗漏可利用漏洞的问题，通过自动化流程和多代理协作，专注于发现具有实际影响的漏洞，而非理论上的缺陷。

**核心功能**

核心功能包括六个阶段：侦察（Recon）以映射应用架构和输入面；漏洞搜寻（Hunt）通过不同攻击类别代理并行攻击代码库；验证（Validate）通过独立代理尝试证伪每个发现，消除误报；报告（Report）生成人类可读的审计报告和详细发现；结构化输出（Structured output）生成机器可读的JSON格式发现；以及独立验证（Independent verification）确保所有事实声明的准确性。

**技术亮点**

技术亮点在于其六阶段的流水线架构，利用并行代理进行侦察和漏洞搜寻，以及对抗性验证机制来减少误报。它还支持多次运行以提高覆盖率，并能读取先前的发现以避免重复。输出的findings.json文件通过report-schema.json进行严格验证。

**适合谁用**

该项目适合需要对代码库进行安全审计的开发者、安全工程师和团队，特别是那些希望自动化漏洞发现流程、提高审计效率和准确性的用户。它也适用于希望构建自己的漏洞发现工具或集成AI驱动安全审计的组织。

### 3. [JustVugg/colibri](https://github.com/JustVugg/colibri) ✰ 35,010

colibrì 是一个轻量级推理引擎，旨在消费级和异构硬件上运行前沿的混合专家 (MoE) 模型，参数规模从 744B 到 2.8T 不等。它将存储、RAM 和 VRAM 视为统一的推理层级，使得大型模型也能在资源有限的机器上运行。

**解决什么问题**
Colibrì 旨在解决前沿大型模型推理对数据中心级硬件的依赖问题。它通过优化推理路径、降低硬件依赖和总成本，使得用户可以在现有硬件上运行 744B 甚至更大的模型。

**核心功能**
Colibrì 的核心功能包括统一的内存层级管理，将 VRAM、RAM 和 NVMe 视为同一份权重的不同放置层级。它实现了权重的 JIT (Just-In-Time) 加载，根据路由热度驱动逐层 LRU 缓存、学习型热门专家固定区和提前一层的预取机制。此外，它支持异构执行，可以在 CPU、CUDA、Metal 和 NUMA 内存等多种硬件上运行。项目还提供了 OpenAI 兼容的 API 和 Web 仪表盘。

**技术亮点**
该项目的技术亮点在于其纯 C 语言实现，零引擎依赖，注重效率和可移植性。它通过 AI 内存分层技术，将模型权重智能地放置在 VRAM、RAM 和 NVMe 中。Colibrì 还采用了专家缓存和权重 JIT 技术，通过测量路由热度来驱动 LRU 缓存和预取，以提高性能。它还支持无损推测解码，例如原生多令牌预测 (MTP) 和语法强制草稿，以在不牺牲质量的情况下生成多个令牌。

**适合谁用**
Colibrì 适合希望在消费级或异构硬件上运行大型 MoE 模型（如 GLM-5.2、Kimi K3）的开发者和研究人员。它也适合那些希望深入了解模型推理过程，并愿意通过实验和贡献来优化性能的用户。对于资源有限但希望运行前沿大型语言模型的人来说，Colibrì 提供了一个可行的解决方案。
